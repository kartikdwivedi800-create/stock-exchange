# Stock Service

Stock Service for Nexus Exchange.

## Details
- Port: `8085`
- Language: Java 21
- Framework: Spring Boot 3

## Endpoints
- **Health Check**: `GET http://localhost:8085/health`
- **Swagger Documentation**: `GET http://localhost:8085/swagger-ui.html`
- **API Documentation (JSON)**: `GET http://localhost:8085/api-docs`
