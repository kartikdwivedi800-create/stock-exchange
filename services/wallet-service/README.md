# Wallet Service

Wallet Service for Nexus Exchange.

## Details
- Port: `8082`
- Language: Java 21
- Framework: Spring Boot 3

## Endpoints
- **Health Check**: `GET http://localhost:8082/health`
- **Swagger Documentation**: `GET http://localhost:8082/swagger-ui.html`
- **API Documentation (JSON)**: `GET http://localhost:8082/api-docs`
