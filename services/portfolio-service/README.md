# Portfolio Service

Portfolio Service for Nexus Exchange.

## Details
- Port: `8084`
- Language: Java 21
- Framework: Spring Boot 3

## Endpoints
- **Health Check**: `GET http://localhost:8084/health`
- **Swagger Documentation**: `GET http://localhost:8084/swagger-ui.html`
- **API Documentation (JSON)**: `GET http://localhost:8084/api-docs`
