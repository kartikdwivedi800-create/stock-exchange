# Order Service

Order Service for Nexus Exchange.

## Details
- Port: `8083`
- Language: Java 21
- Framework: Spring Boot 3

## Endpoints
- **Health Check**: `GET http://localhost:8083/health`
- **Swagger Documentation**: `GET http://localhost:8083/swagger-ui.html`
- **API Documentation (JSON)**: `GET http://localhost:8083/api-docs`
